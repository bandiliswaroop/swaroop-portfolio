# Santhi Swaroop Bandili – Portfolio

Professional portfolio site (HTML, CSS, JS). Serve via XAMPP or any local server.

## Update your profile links

Edit `script.js` and set your real URLs in the `LINKS` object at the top:

```js
const LINKS = {
  github: 'https://github.com/yourusername',
  linkedin: 'https://linkedin.com/in/yourprofile',
};
```

## Resume

Your resume PDF is linked from the Contact section. The file is at `resume/ssresume.pdf`. Replace it anytime to update the downloadable resume.

## Run locally

- **XAMPP:** Place the project in `htdocs` and open `http://localhost/swaroop_portfolio/`
- Or use any static server (e.g. `npx serve .`) from the project folder.
